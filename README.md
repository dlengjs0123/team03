Team03 문정열정 

 

주제: 부산광역시 공공도서관의 ‘자료구입비 비중’과 ‘도서 대출량’ 상관관계 분석 

 

[팀원] 이두헌 문헌정보학과 202606207, 왕은상 문헌정보학과 202606205  

 

[프로젝트 소개] 우리조는 문헌정학과로써 자료구입비 비중이 높을수록 장서화전률이 높을것이다
(사람들이 도서관에 책을 많이 빌리러 올 것이다)라는 가설을 세우고 이를 알아보기위해 부산광역시 공공도서관의 ‘자료구입비 비중’과 ‘도서 대출량’ 상관관계 분석하여 가설을 검증하기로 하였다. 

 

[실행방법] 실행에 앞서 도서관 정보나루에서 인쇄자료 수, 전자자료 수, 대출량, 예산 자료를 다운로드 하였고 이 4개의 엑셀자료를 하나의 csv파일로 병합하려했으나 
데이터 전처리를 하는것이 더 효율적이라 판단되어 위해 구글 코렙을 사용하여 4개의 파일을 하나의 csv파일로 정리하였다. 프로젝트를 실행하기위해 파이썬 터미널에서 다음과 같은 절차를 따른다. 
1. 파이썬 엡을 열고 새로 만들기를 하여 team03.py이라는 이름의 새로운 파일을 하나 만든다. 
2. 재미나이를 활용하여 재미나이가 제시한 코드를 입력하고 터미널을 열어서 ‘steamlit run app_team03.py’ 를 입력한 후 실행한다. 
3. 살행된 프로그램에 데이터 전처리를 통해 정리한 csv 파일을 업로드 한다. 업로드 하면 미리보기로 도서관 5개의 데이터가 제시되고, 분석실행 버튼을 누르면 ‘재료구입비 비중과 장서 회전률 사이의 상관관계에 따른 산점도 그래프’와 ‘장서회전률 상위10개 도서관의 자료구입비 비중이 표시된 막대그래프’가 제시된다. 

 

[라이브러리] streamlit, pandas, matplotlib.pyplot, seaborn
